# Politique de sécurité

## Versions prises en charge

Seule la dernière version publiée sur `main` reçoit des correctifs de sécurité.

## Comptes

La connexion renvoie une seule erreur, que le compte existe ou non ;
l'identifiant de session est régénéré à chaque connexion ; un mot de passe fait
de 6 à 72 octets.

## Signaler une vulnérabilité

Merci de ne pas ouvrir de ticket public pour les problèmes de sécurité.
Signalez-les en privé via GitHub : ouvrez l'[onglet Security](https://github.com/bhrochdi/chess/security)
et choisissez **Report a vulnerability**
([lien direct](https://github.com/bhrochdi/chess/security/advisories/new)).

Indiquez ce qui est concerné, comment le reproduire et ce qu'un attaquant
pourrait en faire. Vous devriez recevoir une réponse sous une semaine. Une fois
le correctif publié, l'avis est rendu public et vous êtes crédité, sauf si vous
préférez rester anonyme.

Les problèmes dans les bibliothèques tierces utilisées par Le Cercle relèvent de
leurs mainteneurs. Si Le Cercle fige une version vulnérable, signalez-le ici.
